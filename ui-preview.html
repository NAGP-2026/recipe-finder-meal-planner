Change 6 — Scroll Progress
Rainbow Progress Bar at Top New

The thin gradient bar at the very top of this page (pinned in position) shows how far the user has scrolled. In the real app it would track actual scroll position using a few lines of JavaScript.

In app.css, add: .scroll-progress {
  position: fixed; top: 0; left: 0; height: 3px; z-index: 9999;
  background: linear-gradient(90deg, #FF6B35, #8B5CF6, #06D6A0);
  box-shadow: 0 0 10px rgba(255,107,53,0.6);
  transition: width 0.1s linear;
}
In +layout.svelte, add: let scrollPct = $state(0);
onMount(() => {
  window.addEventListener('scroll', () => {
    const h = document.body.scrollHeight - window.innerHeight;
    scrollPct = h > 0 ? (window.scrollY / h) * 100 : 0;
  }, { passive: true });
});
// In template:
<div class="scroll-progress" style="width:{scrollPct}%"></div>
